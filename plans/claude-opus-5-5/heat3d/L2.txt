Registers (System V)
- tsteps arrives in rdi, n in rsi, A in rdx, B in rcx. Nothing on the stack.
- rdi becomes 2 * tsteps half-steps; rdx is the source, rcx the destination, swapped after every half-step (first A to B, then B to A).
- Callee-saved rbx, rbp, r12, r13, r14, r15 are pushed at entry and popped before returning.
- r15 = 8*n*n (bytes per i-plane). r8 is i, r9 is j, r10 is k, r11 the end of the vector part over k, 1 + ((n - 2) & -4).
- For each (i, j): rax points at the source line (i, j, 0), at source + 8*((i*n + j)*n); r14 at the destination line at the same offset; rbx = rax - r15 (line i-1), rbp = rax + r15 (line i+1), r12 = rax - 8*n (line j-1), r13 = rax + 8*n (line j+1).
- ymm15 holds 0.125 broadcast (from .rodata); ymm0-ymm5 are temporaries.

Loops
1. For each half-step, for i from 1 to n-2, for j from 1 to n-2 (compute the six line pointers), then along k:
   - Vector part: k from 1 while k < r11, step 4. With c = centre at rax + 8*k:
     d_i = (line i+1 at k) - (c + c) + (line i-1 at k)
     d_j = (line j+1 at k) - (c + c) + (line j-1 at k)
     d_k = (rax + 8*k + 8) - (c + c) + (rax + 8*k - 8)
     result = c + 0.125 * ((d_i + d_j) + d_k), stored to r14 + 8*k.
   - Scalar part: k while k < n - 1, the same formula for one element.
2. Swap rdx and rcx after each half-step; after all half-steps pop the saved registers, vzeroupper, return.

Edge cases
- n = 3: a single interior point per half-step, scalar part only. Boundary elements (any index 0 or n-1) are never written.
- The vector part along k reads at most up to index n-1 of the line.
- tsteps = 1: two half-steps.
- Unaligned vector loads and stores.

Vector instructions
- AVX, 256-bit, separate add, subtract and multiply, in the same order in the vector and scalar parts. One multiplication by 0.125 per point, applied to the sum of the three differences.
