Registers (System V)
- tsteps arrives in rdi, n in rsi, A in rdx, B in rcx. Nothing on the stack.
- rdi becomes the number of half-steps, 2 * tsteps. Each half-step reads from rdx (source) and writes to rcx (destination); afterwards the two pointers are swapped, so the first half-step goes A to B and the second B to A.
- rax is the index i, r8 the end of the vector part, 1 + ((n - 2) & -4), and r9 = n - 1 the end of the interior.
- ymm2 holds 3.0 broadcast to four lanes (loaded from a constant in .rodata); ymm0, ymm1 are temporaries.
- Only caller-saved registers are used; nothing is saved.

Loops
1. For each half-step (while rdi > 0):
   - Vector part: i from 1 while i < r8, step 4: load src[i-1..i+2], src[i..i+3], src[i+1..i+4] (addresses src + 8*i - 8, src + 8*i, src + 8*i + 8), add the three, divide by 3.0, store to dst + 8*i.
   - Scalar part: i while i < n - 1: dst[i] = (src[i-1] + src[i] + src[i+1]) / 3.0.
   - Swap rdx and rcx, decrement rdi.
2. After an even number of half-steps the pointers are back to A and B. vzeroupper, return.

Edge cases
- n = 3: one interior element, only the scalar part runs. Elements 0 and n-1 are never written in either array.
- The highest index read is n-1 (the last interior element reads i+1 = n-1); the vector part ends at least 4 elements before that bound is exceeded.
- tsteps = 1: two half-steps.
- Unaligned vector loads and stores.

Vector instructions
- AVX, 256-bit; separate adds followed by a division, the same operations as the scalar part, so vector and scalar results are identical.
