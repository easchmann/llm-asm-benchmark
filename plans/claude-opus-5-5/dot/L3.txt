Registers (System V)
- n arrives in rdi, x in rsi, y in rdx. The double result is returned in xmm0.
- rcx is the element index i, rax holds n & -4.
- ymm0 is the vector accumulator (four partial sums), ymm1 a temporary. After the reduction xmm0 holds the scalar sum.
- Only caller-saved registers are used; nothing is saved.

Loops
1. Clear ymm0.
2. Vector part: i from 0 while i < rax, step 4: load x[i..i+3] (x + 8*i), multiply by y[i..i+3] (y + 8*i), add to ymm0.
3. Reduce: add the upper 128 bits of ymm0 onto the lower 128 bits, then add the two remaining lanes, leaving the sum in the low lane of xmm0.
4. Scalar part: i while i < n: xmm0 += x[i] * y[i].
5. vzeroupper (keeps xmm0), return with the result in xmm0.

Edge cases
- n < 4: the vector loop is skipped, the reduction of a zero accumulator gives 0.0, the scalar loop computes the whole sum.
- n not a multiple of 4: the scalar loop adds the last n mod 4 products; nothing beyond index n-1 is read.
- Unaligned vector loads.

Vector instructions
- AVX, 256-bit; separate multiply and add (no FMA). Summing in four lanes changes the order of additions, so the result can differ from a sequential sum in the last bits.
