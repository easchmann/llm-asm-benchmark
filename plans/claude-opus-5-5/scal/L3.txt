Registers (System V)
- n arrives in rdi, x in rsi; the scalar a arrives in xmm0. Nothing is on the stack.
- rcx is the element index i, rax holds n & -4 (end of the vector part).
- ymm0 holds a broadcast to four lanes; its low lane is a for the scalar part. ymm1 is a temporary.
- Only caller-saved registers are used; nothing is saved.

Loops
1. Vector part: i from 0 while i < rax, step 4: load x[i..i+3] from x + 8*i, multiply by a, store back to x + 8*i.
2. Scalar part: i while i < n, step 1: x[i] = x[i] * a.
3. vzeroupper, return.

Edge cases
- n = 1, 2 or 3: only the scalar loop runs.
- n not a multiple of 4: the scalar loop handles the remaining 1-3 elements; no access at index n or beyond.
- Unaligned vector loads and stores (8-byte alignment only).

Vector instructions
- AVX, 256-bit, four doubles per vector; VEX-encoded scalar instructions for the tail.
