Registers (System V)
- n arrives in rdi, a in rsi. Nothing on the stack.
- rdi becomes the number of groups (n >> 3); rsi points at the current group and advances by 64 bytes per group.
- The 8 elements of a group are held in rax, rcx, rdx, r8, r9, r10, r11 and rbx (elements 0 to 7, in that order); rbp is a temporary. rbx and rbp are callee-saved: they are pushed at entry and popped before returning.

Loops
1. For each group (while groups remain): load the 8 elements from rsi + 0, 8, ..., 56 into the 8 registers.
2. Apply the 19 compare-exchange steps of the given network, in the given order:
   (0,1) (2,3) (4,5) (6,7) (0,2) (1,3) (4,6) (5,7) (1,2) (5,6) (0,4) (3,7) (1,5) (2,6) (1,4) (3,6) (2,4) (3,5) (3,4).
   Each compare-exchange (p, q) without branches: copy p to the temporary, compare p with q as signed values, and if p > q move q into p and the temporary into q with two conditional moves on the signed "greater" condition (conditional moves do not change the flags, so one comparison serves both).
3. Store the 8 registers back to rsi + 0 ... rsi + 56; advance rsi by 64, decrement the group count.
4. Pop rbp and rbx, return.

Edge cases
- n = 8: one group. n is a positive multiple of 8, so there is no partial group.
- The comparison is signed, so negative values sort first. Equal values are not exchanged.
- Only the current group is read and written.

Vector instructions
- None; the network runs in general-purpose registers with conditional moves.
