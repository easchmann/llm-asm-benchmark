Registers (System V)
- n arrives in rdi, x in rsi. The double result is returned in xmm0.
- rcx is the element index i, rax holds n & -4.
- ymm0 is the vector accumulator of squares, ymm1 a temporary.
- Only caller-saved registers are used; nothing is saved.

Loops
1. Clear ymm0.
2. Vector part: i from 0 while i < rax, step 4: load x[i..i+3] from x + 8*i, square it (multiply by itself), add to ymm0.
3. Reduce the four lanes into the low lane of xmm0 (upper 128 bits onto lower, then the two remaining lanes).
4. Scalar part: i while i < n: xmm0 += x[i] * x[i].
5. Divide the low lane by n (converted to double), take the square root (scalar square root), vzeroupper, return in xmm0.

Edge cases
- n < 4: only the scalar loop runs. n = 1 returns |x[0]|, since sqrt(x*x) is the absolute value.
- n not a multiple of 4: the scalar loop handles the tail; no read beyond index n-1.
- Unaligned vector loads.

Vector instructions
- AVX, 256-bit, separate multiply and add. The sum of squares is computed directly without rescaling.
