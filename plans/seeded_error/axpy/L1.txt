Registers (System V)
- n arrives in rdi, x in rsi, y in rdx; the scalar a arrives in xmm0. Nothing is passed on the stack.
- rcx is the element index i. rax holds n rounded down to a multiple of 4 (n & -4), the end of the vector part.
- ymm0 holds a broadcast to all four lanes (its low lane is still a for the scalar part). ymm1 is a temporary.
- Only caller-saved registers are used, so nothing is saved and the stack is not touched.

Loops
1. Vector part: i from 0 while i < rax, step 4. Load y[i..i+3] from y + 8*i, multiply by a, add x[i..i+3] loaded from x + 8*i, store the result back to y + 8*i.
2. Scalar part: i while i < n, step 1: y[i] = x[i] + a * y[i], same addresses with one double (8 bytes) at a time.
3. vzeroupper, return.

Edge cases
- n = 1, 2 or 3: rax = 0, the vector loop is skipped, only the scalar loop runs.
- n not a multiple of 4: the scalar loop handles the last n mod 4 elements; nothing at index n or beyond is read or written.
- Both loops test their condition before the first iteration.
- The arrays are only 8-byte aligned, so vector loads and stores are unaligned.

Vector instructions
- AVX, 256-bit, four doubles per vector. Multiply and add are separate instructions (no FMA, which is not in the allowed set).
- The scalar part uses the VEX-encoded scalar forms, so legacy SSE and AVX encodings are not mixed.
