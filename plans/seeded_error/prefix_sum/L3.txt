Registers (System V)
- n arrives in rdi, a in rsi, out in rdx. Nothing on the stack.
- rcx is the element index i, rax the running sum, r8 a temporary.
- Only caller-saved registers are used; nothing is saved.

Loops
1. rax = 0.
2. For i from 0 while i < n: store rax to out[i] (out + 8*i), then rax = rax + a[i] (a + 8*i).
3. Return.

Edge cases
- n = 1: out[0] = 0. The sum covers the elements before the position (exclusive prefix sum).
- 64-bit integer addition; overflow wraps, as in two's complement arithmetic.

Vector instructions
- None. Each output depends on the previous one, so a simple scalar loop is used.
