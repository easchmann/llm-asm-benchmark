Registers (System V)
- m arrives in rdi, n in rsi, A in rdx, s in rcx, q in r8, p in r9; r is the seventh argument, on the stack at 8(%rsp), loaded into r10 at entry.
- A has n rows and m columns. rdx is used as the pointer to the current row and advances by 8*m bytes per row; rsi counts the remaining rows; r10 (r) and r8 (q) advance by 8 bytes per row.
- rax is the column index j, r11 = m & -4.
- ymm2 accumulates the dot product of the row with p, ymm4, ymm5 temporaries.
- Only caller-saved registers are used; nothing is saved.

Loops
1. Clear s: j from 0 to m-1 (vector part of four zeros, then scalar), because s is undefined on entry.
2. For each row i (n rows):
   - Clear ymm2.
   - Vector part: j from 0 while j < r11, step 4: load A[i][j..j+3]; ymm2 += A * p[j..j+3]; s[j..j+3] += A * p[j..j+3] (load, add, store).
   - Reduce ymm2 to a scalar; scalar part j while j < m: sum += A[i][j]*p[j]; s[j] += A[i][j]*p[j].
   - Store the sum to q[i]. Advance the row pointer by 8*m, r and q by 8, decrement the row count.
3. vzeroupper, return.

Edge cases
- m < 4: vector parts skipped. m not a multiple of 4: the scalar part handles the tail. n = 1: one row.
- s is cleared before accumulating; q is written once per row.
- Unaligned vector loads and stores.

Vector instructions
- AVX, 256-bit, separate multiply and add.
