Registers (System V)
- n arrives in rdi, x1 in rsi, x2 in rdx, y_1 in rcx, y_2 in r8, A in r9. Nothing on the stack.
- r9 is used as the pointer to the current row of A and advances by 8*n bytes per row.
- r10 is the row index i, r11 the column index j, rax = n & -4.
- ymm2 accumulates the dot product of row i with y_1; ymm3 holds y_2[i] broadcast; ymm4, ymm5 temporaries.
- Only caller-saved registers are used; nothing is saved.

Loops
One pass over A, row by row, doing both products:
1. For each row i from 0 while i < n:
   - Clear ymm2, broadcast y_2[i] (y_2 + 8*i) into ymm3.
   - Vector part: j from 0 while j < rax, step 4: load A[i][j..j+3] (row + 8*j); ymm2 += A * y_1[j..j+3]; x2[j..j+3] = x2[j..j+3] + A * y_2[i] (load, add, store at x2 + 8*j).
   - Reduce ymm2 to a scalar.
   - Scalar part: j while j < n: sum += A[i][j] * y_1[j]; x2[j] += A[i][j] * y_2[i].
   - x1[i] = sum (x1 + 8*i). Advance the row pointer by 8*n.
2. vzeroupper, return.

Edge cases
- n < 4: scalar loops only. n not a multiple of 4: the tail columns are handled by the scalar part; nothing beyond index n-1 is touched.
- x2 keeps its initial values and is only added to; x1 is overwritten.
- Unaligned vector loads and stores.

Vector instructions
- AVX, 256-bit, separate multiply and add. x2 receives the contributions of the rows in row order; the dot product for x1 is summed in four lanes.
