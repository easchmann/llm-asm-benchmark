Registers (System V)
- n arrives in rdi, data in rsi, nbins in rdx, hist in rcx. Nothing on the stack.
- rax is the loop index (first over the bins, then over the data), r8 holds the current data value.
- Only caller-saved registers are used; nothing is saved.

Loops
1. Clear hist: for b from 0 while b < nbins - 1: store the 64-bit value 0 at hist + 8*b. This is needed because hist is undefined on entry.
2. Count: for i from 0 while i < n: r8 = data[i] (data + 8*i); increment the 64-bit counter at hist + 8*r8.
3. Return.

Edge cases
- n = 1: the counting loop runs once.
- Every data value is between 0 and nbins-1, so hist + 8*value is always inside hist; no bounds check is needed.
- Repeated values simply increment the same counter several times.

Vector instructions
- None; the counting loop has data-dependent addresses and is done with scalar 64-bit increments in memory.
