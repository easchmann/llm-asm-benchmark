Registers (System V)
- n arrives in rdi, L in rsi, x in rdx, y in rcx. Nothing on the stack.
- rsi is used as the pointer to the current row of L and advances by 8*n bytes per row.
- r8 is the row index i, r9 the column index j, r10 = i (number of used entries in the row), r11 = r10 & -4.
- ymm0 accumulates the partial sums, ymm1 temporary.
- Only caller-saved registers are used; nothing is saved.

Loops
1. For each row i from 0 while i < n:
   - Clear ymm0. Vector part: j from 0 while j < r11, step 4: ymm0 += L[i][j..j+3] (row + 8*j) * x[j..j+3] (x + 8*j).
   - Reduce to a scalar; scalar part: j while j < i: sum += L[i][j] * x[j].
   - y[i] = sum (y + 8*i). Advance the row pointer by 8*n.
2. vzeroupper, return.

Edge cases
- Only columns 0 to i-1 of row i are read, so the diagonal and the arbitrary values above it are never used (the vector part stops at a multiple of 4 that is at most i).
- Row 0 has no used entries, so y[0] = 0. n = 1 works the same way.
- y is written for every row.

Vector instructions
- AVX, 256-bit, separate multiply and add; four-lane partial sums.
