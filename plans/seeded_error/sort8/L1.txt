Registers (System V)
- n arrives in rdi, a in rsi. Nothing on the stack.
- rdi is turned into the number of groups (n >> 3); rsi points at the current group and advances by 64 bytes per group.
- Within a group: rcx is the outer index i (1 to 7), rax the element being inserted, rdx the inner index j, r8 a temporary.
- Only caller-saved registers are used; nothing is saved.

Loops
1. For each group of 8 (while groups remain): insertion sort of the 8 elements at rsi + 8*0 ... rsi + 8*7:
   - for i from 1 to 7: key = element i; j = i - 1;
     while j >= 0 and element j < key (signed comparison): element j+1 = element j; j = j - 1;
     element j+1 = key.
   - advance rsi by 64, decrement the group count.
2. Return.

Edge cases
- n = 8: one group. n is a positive multiple of 8, so there is no partial group.
- Elements are signed 64-bit; the comparison must be signed (negative values sort last).
- Equal elements are not moved past each other (strict < comparison), and the loop never reads outside the current group (j >= 0 is tested before the comparison).

Vector instructions
- None; a scalar insertion sort on 8 elements is short and has no edge cases.
