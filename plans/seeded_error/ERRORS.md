# Seeded errors

One algorithmic error per kernel, the same at every level. Plans are the teacher plans with the replacements
below; `<kernel>/seeded_ref.c` is `kernels/desc/<kernel>/ref.c` with the same error, used to check that the
tests detect it and to classify answers that reproduce it. Generated by `scripts/plan_variants.py build`.

## 2mm

Error: phase 1 scales by beta instead of alpha: tmp = beta * A * B.

Plan changes:

- `Phase 1 (tmp = alpha * A * B)`
  → `Phase 1 (tmp = beta * A * B)`
- `s = alpha * A[i][k]; broadcast;`
  → `s = beta * A[i][k]; broadcast;`

## 3mm

Error: G is accumulated onto its initial contents instead of being cleared: G = G + E*F.

Plan changes:

- `- Set row i of X to zero (vector and scalar parts over q), because E, F and G have undefined contents.`
  → `- For E and F, set row i of X to zero (vector and scalar parts over q), because they have undefined contents; G is accumulated onto its initial contents.`

## atax

Error: y is not cleared before accumulating.

Plan changes:

- `1. Clear y: for j from 0 while j < r11, store four zero doubles at y + 8*j (step 4); then for j < n store one zero double at y + 8*j (step 1). y must be cleared because its initial contents are undefined.`
  → `1. y keeps its initial contents: the products are added to the values already in y, so it is not cleared.`

## axpy

Error: the scale factor is applied to y instead of x: y = x + a*y.

Plan changes:

- `Load x[i..i+3] from x + 8*i, multiply by a, add y[i..i+3] loaded from y + 8*i,`
  → `Load y[i..i+3] from y + 8*i, multiply by a, add x[i..i+3] loaded from x + 8*i,`
- `y[i] = y[i] + a * x[i]`
  → `y[i] = x[i] + a * y[i]`

## bicg

Error: s is accumulated with p[j] instead of r[i].

Plan changes:

- `, ymm3 holds r[i] broadcast,`
  → `,`
- `- Clear ymm2, broadcast r[i] into ymm3.`
  → `- Clear ymm2.`
- `s[j..j+3] += A * r[i]`
  → `s[j..j+3] += A * p[j..j+3]`
- `s[j] += A[i][j]*r[i].`
  → `s[j] += A[i][j]*p[j].`

## dot

Error: off-by-one loop bound: the sum stops at index n-2.

Plan changes:

- `rax holds n & -4.`
  → `rax holds (n - 1) & -4.`
- `4. Scalar part: i while i < n:`
  → `4. Scalar part: i while i < n - 1:`
- `- n < 4: the vector loop`
  → `- n < 5: the vector loop`
- `- n not a multiple of 4: the scalar loop adds the last n mod 4 products;`
  → `- n - 1 not a multiple of 4: the scalar loop adds the remaining products;`

## gemm

Error: C is scaled by beta after the products are added: C = beta*(C + alpha*A*B).

Plan changes:

- `a. Scale the row by beta: vector part j < rbx step 4 (C row + 8*j), scalar part j < nj.
   b. For k from 0 while k < nk: s = alpha * A[i][k] (A row + 8*k); broadcast s; row k of B at r10.
      Vector part: C[i][j..j+3] += s * B[k][j..j+3]; scalar part for the remaining columns. Advance r10 by 8*nj.`
  → `a. For k from 0 while k < nk: s = alpha * A[i][k] (A row + 8*k); broadcast s; row k of B at r10.
      Vector part: C[i][j..j+3] += s * B[k][j..j+3]; scalar part for the remaining columns. Advance r10 by 8*nj.
   b. Scale the row by beta: vector part j < rbx step 4 (C row + 8*j), scalar part j < nj.`

## gemver

Error: v1 and v2 are swapped in the rank-2 update: A + u1*v2^T + u2*v1^T.

Plan changes:

- `A[i][j] = (A[i][j] + u1[i]*v1[j]) + u2[i]*v2[j]`
  → `A[i][j] = (A[i][j] + u1[i]*v2[j]) + u2[i]*v1[j]`

## gesummv

Error: y = alpha * (A x + B x) instead of alpha * A x + beta * B x.

Plan changes:

- `y[i] = alpha * A-sum + beta * B-sum (y + 8*i).`
  → `y[i] = alpha * (A-sum + B-sum) (y + 8*i).`

## heat3d

Error: the centre value is not added back (only the scaled second differences).

Plan changes:

- `result = ((0.125*d_i + 0.125*d_j) + 0.125*d_k) + c, in this order (the centre value is added last), stored`
  → `result = (0.125*d_i + 0.125*d_j) + 0.125*d_k, in this order, stored`
- `result = c + 0.125*d_i + 0.125*d_j + 0.125*d_k, stored`
  → `result = 0.125*d_i + 0.125*d_j + 0.125*d_k, stored`
- `result = c + 0.125 * ((d_i + d_j) + d_k), stored`
  → `result = 0.125 * ((d_i + d_j) + d_k), stored`

## histogram

Error: off-by-one clearing bound: the last bin is not cleared.

Plan changes:

- `for b from 0 while b < nbins:`
  → `for b from 0 while b < nbins - 1:`
- `- nbins = 1 or n = 1: the loops run once.`
  → `- n = 1: the counting loop runs once.`

## jacobi1d

Error: one half-step per time step instead of two (tsteps half-steps in total).

Plan changes:

- `- rdi becomes the number of half-steps, 2 * tsteps.`
  → `- rdi is the number of half-steps, tsteps (one half-step per time step).`
- `2. After an even number of half-steps the pointers are back to A and B. vzeroupper, return.`
  → `2. vzeroupper, return.`
- `- tsteps = 1: two half-steps.`
  → `- tsteps = 1: one half-step.`

## jacobi2d

Error: wrong stencil coefficient: 0.25 instead of 0.2.

Plan changes:

- `holds 0.2 broadcast`
  → `holds 0.25 broadcast`
- `multiply by 0.2,`
  → `multiply by 0.25,`

## lower_bound

Error: <= instead of < in the comparison (returns upper_bound).

Plan changes:

- `) < key using a signed comparison`
  → `) <= key using a signed comparison`
- `- Key smaller than or equal to every element: the result is 0. Key larger than every element:`
  → `- Key smaller than every element: the result is 0. Key larger than or equal to every element:`
- `- Repeated values: the search keeps moving hi down on equality, so it returns the first position whose element is not smaller than the key.`
  → `- Repeated values: the search moves lo up on equality, so it returns the first position whose element is larger than the key.`

## mvt

Error: x1 is overwritten instead of accumulated.

Plan changes:

- `- x1[i] = x1[i] + sum (x1 + 8*i).`
  → `- x1[i] = sum (x1 + 8*i).`
- `- x1 and x2 keep their initial values and are only added to.`
  → `- x2 keeps its initial values and is only added to; x1 is overwritten.`

## nrm2

Error: divides the sum of squares by n before the square root (RMS instead of the 2-norm).

Plan changes:

- `5. Take the square root of the low lane (scalar square root),`
  → `5. Divide the low lane by n (converted to double), take the square root (scalar square root),`

## popcount

Error: the total is taken from the low byte of the product instead of the top byte.

Plan changes:

- `- v = (v * 0x0101...) >> 56             (64-bit multiply, keep the low 64 bits, logical shift; the top byte is the total)`
  → `- v = (v * 0x0101...) & 0xFF            (64-bit multiply, keep the low 64 bits; the low byte is the total)`

## prefix_sum

Error: exclusive instead of inclusive prefix sum.

Plan changes:

- `2. For i from 0 while i < n: rax = rax + a[i] (a + 8*i), store rax to out[i] (out + 8*i).`
  → `2. For i from 0 while i < n: store rax to out[i] (out + 8*i), then rax = rax + a[i] (a + 8*i).`
- `- n = 1: out[0] = a[0]. The sum includes the element at the same position (inclusive prefix sum).`
  → `- n = 1: out[0] = 0. The sum covers the elements before the position (exclusive prefix sum).`

## scal

Error: divides by a instead of multiplying.

Plan changes:

- `multiply by a, store back`
  → `divide by a, store back`
- `x[i] = x[i] * a.`
  → `x[i] = x[i] / a.`

## sort8

Error: sorts each group in descending instead of ascending order.

Plan changes:

- `and if p > q move q into p and the temporary into q with two conditional moves on the signed "greater" condition`
  → `and if p < q move q into p and the temporary into q with two conditional moves on the signed "less" condition`
- `- The comparison is signed, so negative values sort first.`
  → `- The comparison is signed, so negative values sort last.`
- `element j > key (signed comparison)`
  → `element j < key (signed comparison)`
- `the comparison must be signed (negative values sort first)`
  → `the comparison must be signed (negative values sort last)`
- `(strict > comparison)`
  → `(strict < comparison)`

## spmv

Error: the last nonzero of every row is skipped: end = rowptr[i+1] - 1.

Plan changes:

- `holds the end position rowptr[i+1],`
  → `holds the end position rowptr[i+1] - 1,`
- `end = rowptr[i+1] (at rdx + 8);`
  → `end = rowptr[i+1] - 1 (at rdx + 8, minus one);`

## syrk

Error: the upper triangle (j >= i) is computed instead of the lower one.

Plan changes:

- `For j from 0 while j <= i (lower triangle including the diagonal):`
  → `For j from i while j < n (upper triangle including the diagonal):`
- `r10 at row j of A (starts at A for every i,`
  → `r10 at row j of A (starts at row i of A for every i,`
- `- Entries with j > i are never read or written.`
  → `- Entries with j < i are never read or written.`

## trmm

Error: A is read transposed: A[i][k] instead of A[k][i].

Plan changes:

- `rax points at A[k][i] (A + 8*(k*m + i)), which advances by 8*m per k.`
  → `rax points at A[i][k] (A + 8*(i*m + k)), which advances by 8 per k.`
- `A[k][i]`
  → `A[i][k]`
- `entries of A with k <= i are never read.`
  → `entries A[i][k] with k <= i are never read.`

## trmv

Error: the diagonal is excluded: j < i instead of j <= i.

Plan changes:

- `r10 = i + 1 (number of used entries in the row)`
  → `r10 = i (number of used entries in the row)`
- `scalar part: j while j <= i:`
  → `scalar part: j while j < i:`
- `- Only columns 0 to i of row i are read, so the arbitrary values above the diagonal are never used (the vector part stops at a multiple of 4 that is at most i+1).`
  → `- Only columns 0 to i-1 of row i are read, so the diagonal and the arbitrary values above it are never used (the vector part stops at a multiple of 4 that is at most i).`
- `- Row 0 uses only L[0][0].`
  → `- Row 0 has no used entries, so y[0] = 0.`
