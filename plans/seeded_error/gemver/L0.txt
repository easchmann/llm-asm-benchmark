Registers (System V)
- n arrives in rdi, A in rsi, u1 in rdx, v1 in rcx, u2 in r8, v2 in r9; alpha in xmm0, beta in xmm1. w, x, y and z are on the stack at 8, 16, 24 and 32 bytes above rsp on entry.
- Callee-saved rbx, r12, r13, r14, r15 are pushed at entry (40 bytes), so w, x, y, z are then at 48, 56, 64 and 72(%rsp); load them into r10 (w), r11 (x), rbx (y) and r12 (z). Pop in reverse order before returning.
- r13 points at the current row of A (advances 8*n), r14 is the row index, rax the column index, r15 = n & -4.
- xmm0 and xmm1 keep alpha and beta; ymm2-ymm7 are temporaries and broadcasts.

Loops
1. Update A: for each row i: broadcast u1[i] and u2[i]; A[i][j] = (A[i][j] + u1[i]*v2[j]) + u2[i]*v1[j] for all j (vector part, scalar tail).
2. x += beta * A^T y, using the updated A row by row: for each row r: t = beta * y[r] broadcast; x[c] += t * A[r][c] for all c (vector part, scalar tail).
3. x += z: for all c, x[c] = x[c] + z[c] (vector part, scalar tail).
4. w += alpha * A x: for each row i: d = dot product of A row i with the updated x (four-lane vector sum, reduce, scalar tail); w[i] = w[i] + alpha * d.
5. Pop the registers, vzeroupper, return.

Edge cases
- n < 4: only scalar tails run; n not a multiple of 4: tails handle the last columns.
- The steps must run in this order: step 2 uses the fully updated A, step 4 uses x after steps 2 and 3.
- Unaligned vector loads and stores.

Vector instructions
- AVX, 256-bit, separate multiply and add.
