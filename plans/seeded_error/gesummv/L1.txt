Registers (System V)
- n arrives in rdi, A in rsi, B in rdx, tmp in rcx, x in r8, y in r9; alpha in xmm0, beta in xmm1. Nothing on the stack.
- rsi and rdx are used as the pointers to the current rows of A and B and advance by 8*n bytes per row.
- r10 is the row index i, r11 the column index j, rax = n & -4.
- ymm2 and ymm3 accumulate the partial sums for A and B; ymm4, ymm5 temporaries. xmm0 and xmm1 are kept unchanged.
- Only caller-saved registers are used; nothing is saved.

Loops
1. For each row i from 0 while i < n:
   - Clear ymm2 and ymm3.
   - Vector part: j from 0 while j < rax, step 4: load x[j..j+3] (x + 8*j); ymm2 += A row[j..j+3] * x; ymm3 += B row[j..j+3] * x.
   - Reduce both accumulators to scalars (upper half onto lower half, then the two lanes).
   - Scalar part: j while j < n: add A[i][j]*x[j] and B[i][j]*x[j].
   - tmp[i] = A-sum (tmp + 8*i); y[i] = alpha * (A-sum + B-sum) (y + 8*i).
   - Advance the row pointers by 8*n.
2. vzeroupper, return.

Edge cases
- n < 4: vector parts skipped. n not a multiple of 4: the scalar part handles the last columns; no read beyond column n-1.
- y is written for every i, so its undefined initial contents do not matter.
- Unaligned vector loads.

Vector instructions
- AVX, 256-bit, separate multiply and add; the four-lane sums change the order of additions (results agree up to rounding).
