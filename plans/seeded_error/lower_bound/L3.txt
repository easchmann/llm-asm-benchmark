Registers (System V)
- n arrives in rdi, sorted in rsi, q in rdx, keys in rcx, idx in r8. Nothing on the stack.
- rdx is used as the count of remaining keys; rcx and r8 advance by 8 bytes per key.
- r10 holds the current key, r11 is lo, rax is hi, r9 is mid.
- Only caller-saved registers are used; nothing is saved.

Loops
1. For each key (while rdx > 0):
   - r10 = key (8 bytes at rcx); lo = 0, hi = n.
   - Binary search while lo < hi: mid = (lo + hi) >> 1 (logical shift; lo + hi cannot overflow); if sorted[mid] (sorted + 8*mid) <= key using a signed comparison, lo = mid + 1, else hi = mid.
   - Store lo to idx (8 bytes at r8); advance rcx and r8 by 8, decrement rdx.
2. Return.

Edge cases
- Key smaller than every element: the result is 0. Key larger than or equal to every element: lo reaches n and n is stored.
- Repeated values: the search moves lo up on equality, so it returns the first position whose element is larger than the key.
- n = 1: one comparison. Negative values are handled because all comparisons are signed.
- Only indices 0 to n-1 of sorted are ever read (mid < hi <= n).

Vector instructions
- None; each search is a scalar loop with data-dependent branches.
