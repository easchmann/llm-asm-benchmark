Registers (System V)
- nrows arrives in rdi, ncols in rsi, rowptr in rdx, col in rcx, val in r8, x in r9; y is the seventh argument and is on the stack at 8(%rsp) on entry. It is loaded into r10 at the start.
- rdi counts the remaining rows; rdx advances by 8 bytes per row (points at rowptr[i]) and r10 by 8 bytes per row (points at y[i]).
- rax is k (the current nonzero position), rsi (ncols is not needed) holds the end position rowptr[i+1] - 1, r11 holds col[k].
- xmm0 is the row sum, xmm1 a temporary.
- Only caller-saved registers are used; nothing is saved and the stack is not otherwise touched.

Loops
1. For each row (while rdi > 0):
   - k = rowptr[i] (8 bytes at rdx), end = rowptr[i+1] - 1 (at rdx + 8, minus one); sum = 0.0.
   - while k < end: r11 = col[k] (col + 8*k); sum += val[k] (val + 8*k) * x[col[k]] (x + 8*r11); k = k + 1.
   - store sum to y[i] (at r10); advance rdx and r10 by 8, decrement rdi.
2. Return.

Edge cases
- Empty rows (rowptr[i] = rowptr[i+1]): the inner loop is skipped and y[i] = 0.0 is stored; y must always be written because it is undefined on entry.
- nrows = 1: one row. rowptr has nrows+1 entries, so reading rowptr[i+1] is always valid.
- The products are added in the order of k, like a sequential sum.

Vector instructions
- None; the column indices are irregular, so the loop is scalar (VEX-encoded scalar double instructions).
