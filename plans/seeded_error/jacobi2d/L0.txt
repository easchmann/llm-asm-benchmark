Registers (System V)
- tsteps arrives in rdi, n in rsi, A in rdx, B in rcx. Nothing on the stack.
- rdi becomes 2 * tsteps half-steps; rdx is the source and rcx the destination of the current half-step, swapped after each one.
- rbx and r12 are callee-saved and are pushed at entry and popped before returning.
- Per row: r10 points at the source row i, rbx at source row i-1, r12 at source row i+1, r11 at the destination row i. All four advance by 8*n bytes per row. r8 is the row index i (1 to n-2), r9 the column index j, rax the end of the vector part, 1 + ((n - 2) & -4).
- ymm15 holds 0.25 broadcast (from a constant in .rodata); ymm0-ymm2 are temporaries.

Loops
1. For each half-step:
   - Set the row pointers to row 1 (source + 8*n, its neighbours source and source + 16*n, destination + 8*n).
   - For each row i from 1 while i < n - 1:
     - Vector part: j from 1 while j < rax, step 4: sum = centre (row i, column j) + left (column j-1) + right (column j+1) + row i+1 (column j) + row i-1 (column j), added in this order, multiply by 0.25, store to the destination row at column j. The addresses are row pointer + 8*j, with -8 and +8 for left and right.
     - Scalar part: j while j < n - 1, the same formula on one element.
     - Advance the four row pointers by 8*n, increment i.
   - Swap rdx and rcx.
2. Pop r12 and rbx, vzeroupper, return.

Edge cases
- n = 3: a single interior element, scalar part only. Border rows and columns are never written.
- The vector part never reads beyond column n-1 of a row: its last load starts at most at column n-4.
- The sum is formed in the same order in the vector and scalar parts.
- Unaligned vector loads and stores.

Vector instructions
- AVX, 256-bit, separate add and multiply instructions.
