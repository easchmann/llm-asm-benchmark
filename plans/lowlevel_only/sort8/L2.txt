Registers (System V)
- n arrives in rdi, a in rsi. Nothing on the stack.
- rdi can hold the number of groups (n >> 3); rsi points at the current group, advancing by 64 bytes per group.
- rcx holds the outer index i, rax the element being inserted, rdx the inner index j, r8 a temporary.
- Only caller-saved registers are used; nothing is saved.

Memory and comparisons
- Element e of the group is at rsi + 8*e (offsets 0 to 56).
- Elements are signed 64-bit; comparisons must be signed.

Vector instructions
- None; scalar code.
