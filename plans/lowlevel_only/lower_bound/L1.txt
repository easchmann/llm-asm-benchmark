Registers (System V)
- n arrives in rdi, sorted in rsi, q in rdx, keys in rcx, idx in r8. Nothing on the stack.
- rdx can be used as the count of remaining keys; rcx and r8 advance by 8 bytes per key.
- r10 holds the current key, r11 is lo, rax is hi, r9 is mid.
- Only caller-saved registers are used; nothing is saved.

Memory and comparisons
- sorted[mid] is at sorted + 8*mid; keys and idx entries are 8 bytes.
- All comparisons are signed (negative values are handled). The halving shift is logical.

Vector instructions
- None; scalar code with data-dependent branches.
