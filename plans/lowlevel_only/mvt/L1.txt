Registers (System V)
- n arrives in rdi, x1 in rsi, x2 in rdx, y_1 in rcx, y_2 in r8, A in r9. Nothing on the stack.
- r9 can serve as the pointer to the current row of A (row stride 8*n bytes).
- r10 holds the row index, r11 the column index, rax = n & -4.
- ymm2 is a vector accumulator; ymm3 holds y_2[i] broadcast; ymm4, ymm5 temporaries.
- Only caller-saved registers are used; nothing is saved.

Memory and tails
- A[i][j] is at A + 8*(i*n + j); vector elements at base + 8*index.
- Vector parts cover columns below n & -4; scalar instructions handle the tail columns; nothing beyond index n-1 is touched. n < 4: scalar only.
- A vector accumulator is reduced to a scalar (upper 128 bits onto lower, then the two lanes).
- Unaligned vector loads and stores.
- vzeroupper before returning.

Vector instructions
- AVX, 256-bit, separate multiply and add; four-lane partial sums.
