=== axpy
Registers (System V)
- n arrives in rdi, x in rsi, y in rdx; the scalar a arrives in xmm0. Nothing is passed on the stack.
- rcx holds the element index. rax holds n rounded down to a multiple of 4 (n & -4), the end of the vector part.
- ymm0 holds a broadcast to all four lanes (its low lane is still a for the scalar part). ymm1 is a temporary.
- Only caller-saved registers are used, so nothing is saved and the stack is not touched.

Memory and tails
- Element i of a double array is at base + 8*i.
- The vector part covers indices below n & -4; the last n mod 4 elements use scalar instructions, one double (8 bytes) at a time. Nothing at index n or beyond is read or written.
- n = 1, 2 or 3: n & -4 = 0, so only scalar instructions run.
- The arrays are only 8-byte aligned, so vector loads and stores are unaligned.
- vzeroupper before returning.

Vector instructions
- AVX, 256-bit, four doubles per vector. Multiply and add are separate instructions (no FMA, which is not in the allowed set).
- The scalar part uses the VEX-encoded scalar forms, so legacy SSE and AVX encodings are not mixed.
=== scal
Registers (System V)
- n arrives in rdi, x in rsi; the scalar a arrives in xmm0. Nothing is on the stack.
- rcx holds the element index, rax holds n & -4 (end of the vector part).
- ymm0 holds a broadcast to four lanes; its low lane is a for the scalar part. ymm1 is a temporary.
- Only caller-saved registers are used; nothing is saved.

Memory and tails
- Element i is at x + 8*i.
- The vector part covers indices below n & -4; the remaining 1-3 elements use scalar instructions. No access at index n or beyond.
- n = 1, 2 or 3: only scalar instructions run.
- Unaligned vector loads and stores (8-byte alignment only).
- vzeroupper before returning.

Vector instructions
- AVX, 256-bit, four doubles per vector; VEX-encoded scalar instructions for the tail.
=== nrm2
Registers (System V)
- n arrives in rdi, x in rsi. The double result is returned in xmm0.
- rcx holds the element index, rax holds n & -4.
- ymm0 is the vector accumulator, ymm1 a temporary.
- Only caller-saved registers are used; nothing is saved.

Memory and tails
- Element i is at x + 8*i.
- The vector part covers indices below n & -4; the tail elements use scalar instructions. No read beyond index n-1.
- n < 4: only scalar instructions run.
- Reduction of the vector accumulator into the low lane of xmm0: add the upper 128 bits onto the lower 128 bits, then add the two remaining lanes.
- Unaligned vector loads.
- The square root is a scalar square root instruction. vzeroupper before returning, the result in xmm0.

Vector instructions
- AVX, 256-bit, separate multiply and add.
=== dot
Registers (System V)
- n arrives in rdi, x in rsi, y in rdx. The double result is returned in xmm0.
- rcx holds the element index, rax holds n & -4.
- ymm0 is the vector accumulator (four partial sums), ymm1 a temporary. After the reduction xmm0 holds the scalar value.
- Only caller-saved registers are used; nothing is saved.

Memory and tails
- Element i is at x + 8*i and y + 8*i.
- The vector part covers indices below n & -4; the last n mod 4 elements use scalar instructions. Nothing beyond index n-1 is read.
- n < 4: the vector part is skipped and the reduction of a zero accumulator gives 0.0.
- Reduction: add the upper 128 bits of ymm0 onto the lower 128 bits, then add the two remaining lanes, leaving the value in the low lane of xmm0.
- Unaligned vector loads.
- vzeroupper (keeps xmm0) before returning with the result in xmm0.

Vector instructions
- AVX, 256-bit; separate multiply and add (no FMA). Using four lanes changes the order of additions, so the result can differ from a sequential sum in the last bits.
=== atax
Registers (System V)
- All six arguments arrive in registers, none on the stack: m in rdi, n in rsi, A in rdx, x in rcx, y in r8, tmp in r9.
- rdx can serve as the pointer to the current row of A, advanced by 8*n bytes per row, so no separate row index register is needed; rdi can count rows down; r9 can point at tmp[i].
- r10 holds the column index. r11 holds n rounded down to a multiple of 4 (n & -4), the end of the vector part.
- Only caller-saved registers are used (rdi, rsi, rdx, rcx, r8, r9, r10, r11, ymm0-ymm5), so nothing is pushed or saved and the stack is not touched.

Memory and tails
- A[i][j] is at A + 8*(i*n + j); x[j], y[j] at base + 8*j; tmp[i] at tmp + 8*i.
- Every vector part covers columns below n & -4 (four doubles at a time) and scalar instructions handle the last n mod 4 columns; no load or store touches index n or beyond in any array.
- n = 1, 2 or 3: r11 = 0, so every vector part is skipped and only scalar instructions run.
- A four-lane accumulator is reduced to one scalar by adding the upper 128 bits onto the lower 128 bits, then the two remaining lanes.
- A scalar is broadcast to four lanes from memory (for example from tmp[i]).
- Arrays of doubles are only guaranteed 8-byte alignment: all vector loads and stores are unaligned.
- Clear the upper halves of the ymm registers (vzeroupper) before returning.

Vector instructions
- AVX with 256-bit registers (4 doubles per vector). No FMA, since FMA is not in the allowed set: multiply and add are separate instructions.
- Scalar operations use the VEX-encoded (AVX) forms as well, to avoid mixing legacy SSE and AVX encodings.
- Four-lane partial sums change the order of additions; results agree up to rounding.

- Unaligned vector loads and stores.

=== gemver
Registers (System V)
- n arrives in rdi, A in rsi, u1 in rdx, v1 in rcx, u2 in r8, v2 in r9; alpha in xmm0, beta in xmm1. w, x, y and z are on the stack at 8, 16, 24 and 32 bytes above rsp on entry.

Memory and tails

- Four-lane vector sums are reduced to a scalar.
- Unaligned vector loads and stores.
- Pop the registers, vzeroupper, return.

=== gemm
Registers (System V)

=== 2mm
Registers (System V)
- ni arrives in rdi, nj in rsi, nk in rdx, nl in rcx, tmp in r8, A in r9; B, C and D are on the stack. alpha arrives in xmm0, beta in xmm1.
- Callee-saved rbx, rbp, r12, r13, r14, r15 are pushed at entry (48 bytes), so B, C and D are then at 56(%rsp), 64(%rsp) and 72(%rsp); load them into r10 (B), r11 (C) and r12 (D). Pop in reverse order before returning.
- Index and row-pointer registers: rbx, rbp, rax (indices), r13, r14, r15 (row pointers); r9 can be reused for the end of the vector part (row length & -4) once A's row pointer is set.
- xmm0 (alpha) and xmm1 (beta) stay unchanged; ymm3 holds beta broadcast; ymm2 a broadcast scalar, ymm4, ymm5 temporaries.

Memory and tails
- Row strides are 8*nj (tmp, B), 8*nk (A) and 8*nl (C, D) bytes. No element beyond the end of any row is accessed.
- Vector parts cover row lengths & -4, four doubles at a time; scalar tails handle lengths that are not a multiple of 4; vector parts are skipped whenever the row length is below 4.
- Unaligned vector loads and stores.
- Pop the registers, vzeroupper, return.

Vector instructions
- AVX, 256-bit, separate multiply and add.
=== 3mm

Memory and tails
- Vector parts cover row lengths & -4; scalar tails handle lengths that are not a multiple of 4; vector parts are skipped for rows shorter than 4.
- Unaligned vector loads and stores.

=== heat3d

- The vector part along k reads at most up to index n-1 of the line.
- Unaligned vector loads and stores.

=== spmv
Registers (System V)
- nrows arrives in rdi, ncols in rsi, rowptr in rdx, col in rcx, val in r8, x in r9; y is the seventh argument and is on the stack at 8(%rsp) on entry. It is loaded into r10 at the start.

Vector instructions

=== popcount
Registers (System V)
- n arrives in rdi, a in rsi, counts in rdx. Nothing on the stack.
- rdi can be used as the count of remaining elements; rsi and rdx can advance by 8 bytes per element, so no index register is needed.
- rax holds the current value, rcx is a temporary.
- r8, r9, r10, r11 hold the 64-bit constants (each loaded once with a 64-bit immediate move).
- Only caller-saved registers are used; nothing is saved.

Memory and arithmetic
- Elements are 8 bytes. All shifts are logical (unsigned). Multiplication is a 64-bit multiply keeping the low 64 bits.
- The result is stored as a full 64-bit value.

Vector instructions
- None. The POPCNT instruction is not part of SSE2, AVX or AVX2, so it may not be used; the work is done in general-purpose registers.

=== sort8.L0
Registers (System V)
- n arrives in rdi, a in rsi. Nothing on the stack.
- rdi can hold the number of groups (n >> 3); rsi points at the current group, advancing by 64 bytes per group.
- The 8 elements of a group are held in rax, rcx, rdx, r8, r9, r10, r11 and rbx (elements 0 to 7, in that order); rbp is a temporary. rbx and rbp are callee-saved: they are pushed at entry and popped before returning.

Memory and comparisons
- Element e of the group is at rsi + 8*e (offsets 0, 8, ..., 56).
- Exchanging two registers p and q when p > q without branches: copy p to the temporary, compare p with q as signed values, and if p > q move q into p and the temporary into q with two conditional moves on the signed "greater" condition (conditional moves do not change the flags, so one comparison serves both).
- Pop rbp and rbx, return.

Vector instructions
- None; only general-purpose registers with conditional moves.
