Algorithm
1. s = 0.
2. For i from 0 while i < n: s = s + a[i]; out[i] = s.
3. Return.

Edge cases
- n = 1: out[0] = a[0]. The sum includes the element at the same position (inclusive prefix sum).
- 64-bit integer addition; overflow wraps, as in two's complement arithmetic.
- Each output depends on the previous one.
