Algorithm
1. For each row i from 0 while i < n:
   For j from 0 while j <= i (lower triangle including the diagonal):
   - Dot product d = sum over k (k < m) of A[i][k] * A[j][k] (both rows of A are contiguous).
   - C[i][j] = beta * C[i][j] + alpha * d.
2. Return.

Edge cases
- Entries with j > i are never read or written.
- m = 1: single products. n = 1: only C[0][0].
