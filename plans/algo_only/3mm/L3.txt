Algorithm
Each of the three products X = Y * Z (X is p x q, Y is p x r, Z is r x q) uses the same loop nest.
1. Three products, in this order:
   a. E = A * B: p = ni, r = nk, q = nj.
   b. F = C * D: p = nj, r = nm, q = nl.
   c. G = E * F: p = ni, r = nj, q = nl.
   For each product, for each row i:
   - Set row i of X to zero (all q entries), because E, F and G have undefined contents.
   - For k from 0 while k < r: X[i][j] = X[i][j] + Y[i][k] * Z[k][j] for all j < q.
2. Return.

Edge cases
- Any size may be 1.
- The third product must start only after E and F are complete.
- Each output element accumulates its products in increasing k.
