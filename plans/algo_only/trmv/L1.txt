Algorithm
1. For each row i from 0 while i < n:
   - sum = 0; for j from 0 while j <= i: sum = sum + L[i][j] * x[j].
   - y[i] = sum.
2. Return.

Edge cases
- Only columns 0 to i of row i are read, so the arbitrary values above the diagonal are never used.
- Row 0 uses only L[0][0]. n = 1 works the same way.
- y is written for every row.
