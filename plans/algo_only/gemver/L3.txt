Algorithm
1. Update A: for each row i, for all j: A[i][j] = (A[i][j] + u1[i]*v1[j]) + u2[i]*v2[j].
2. x += beta * A^T y, using the updated A row by row: for each row r: t = beta * y[r]; x[c] = x[c] + t * A[r][c] for all c.
3. x += z: for all c, x[c] = x[c] + z[c].
4. w += alpha * A x: for each row i: d = sum over j of A[i][j] * x[j] with the updated x; w[i] = w[i] + alpha * d.
5. Return.

Edge cases
- n = 1: every step works on single elements.
- The steps must run in this order: step 2 uses the fully updated A, step 4 uses x after steps 2 and 3.
