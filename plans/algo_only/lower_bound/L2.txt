Algorithm
1. For each key t from 0 while t < q:
   - lo = 0, hi = n.
   - Binary search while lo < hi: mid = (lo + hi) / 2 (lo + hi cannot overflow); if sorted[mid] < keys[t] (signed values), lo = mid + 1, else hi = mid.
   - idx[t] = lo.
2. Return.

Edge cases
- Key smaller than or equal to every element: the result is 0. Key larger than every element: lo reaches n and n is stored.
- Repeated values: the search keeps moving hi down on equality, so it returns the first position whose element is not smaller than the key.
- n = 1: one comparison. Negative values are handled because all comparisons are signed.
- Only indices 0 to n-1 of sorted are ever read (mid < hi <= n).
